# Transball GL for GFOS

The AmiCradle Team's port of Transball GL (Santiago Ontanon Villar's
cavern flying game: carry the energy sphere back to the top) to GFOS:
AmigaOS 3.2 with GFOpenUp, 68040/68060 + FPU, on GFOpenUp's SDL 2 and
OpenGL (GFOpenGPU). It ships as a release archive with an Installer and as
the GFOpenUp part Parts/TransballGL.

Upstream is fetched at build time (package/transballgl.lock); this
repository holds only the Amiga port. See [AMIGA_PORT.md](AMIGA_PORT.md).
